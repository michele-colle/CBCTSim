# Denoise + Despeckle for HU → Material Classification

Tools to reduce CT-noise speckle in the MC-GPU label phantom produced by
`dicom_to_mcgpu`. Two parts:

1. **`../test_denoise_despeckle.py`** — Python evaluation harness (DICOM space,
   fast iteration, before/after PNGs). Used to pick the parameters.
2. **C++ port in `../dicom_to_mcgpu.cpp`** — the same two stages in the single
   `dicom_to_mcgpu` executable, gated by the master switch `denoise`
   (true/false, default false):
   - `median_radius` — 3D median filter on the source HU (`itk::MedianImageFilter`)
     before resampling/classification.
   - `despeckle_min_size` — connected-component despeckle in DICOM space:
     components of a treated label smaller than this many voxels are removed and
     their HU is rewritten from the nearest surviving voxel (multi-source BFS),
     so the downstream trilinear resampling path is unchanged.

Label scheme: `0=air, 1=fat, 2=soft, 3=spongiosa, 4=cortical` (5=implant,
10=carbon, 11=foam are added later by overlays and are not affected).

## Quick test (baseline vs denoised)

Two ready-made cfgs live in this folder. Both read the real head CT and write a
thin 30 mm slab (100 slices) — fast, but median+despeckle still process the
**full** DICOM volume.

```bash
cd /home/colle/CBCTSim/ICRPPhantomToMCGPU

# denoised: median radius 1 + despeckle min_size 20, 6-conn, labels 0 3 4
build/dicom_to_mcgpu denoise_checks/test_denoise.cfg

# baseline: everything off (identical geometry)
build/dicom_to_mcgpu denoise_checks/test_baseline.cfg
```

Expected runtime: ~35 s each (dominated by the ~15 s DICOM read; median ≈ 4 s,
despeckle ≈ 7 s on the 1.04-Gvoxel head CT).

Outputs (uint8 label volumes, dims in the filename, X fastest):

```
denoise_checks/output/denoised/MCGPU_vox_2134x2134x100/MCGPU_vox_5labels_2134x2134x100.raw
denoise_checks/output/baseline/MCGPU_vox_2134x2134x100/MCGPU_vox_5labels_2134x2134x100.raw
```

The two files have identical geometry and can be compared voxel-by-voxel:

```python
import numpy as np
shape = (100, 2134, 2134)  # (nz, ny, nx) from the filename
b = np.fromfile("denoise_checks/output/baseline/MCGPU_vox_2134x2134x100/MCGPU_vox_5labels_2134x2134x100.raw", np.uint8).reshape(shape)
d = np.fromfile("denoise_checks/output/denoised/MCGPU_vox_2134x2134x100/MCGPU_vox_5labels_2134x2134x100.raw", np.uint8).reshape(shape)
print("changed voxels:", (b != d).sum(), "=", 100 * (b != d).mean(), "%")
```

What to look for: isolated speckles (spongiosa/fat islands inside brain, air
bubbles inside tissue) gone in the denoised volume, real anatomy (skull,
sinuses, tissue boundaries) intact. Expect ~1–3 % of voxels reclassified.

## Knobs (cfg keys)

| key | default | meaning |
|---|---|---|
| `denoise` | false | **master switch**: gates both stages below |
| `median_radius` | 0 | median filter radius in voxels (1 ⇒ 3×3×3 kernel); 0 = off |
| `despeckle_min_size` | 0 | components smaller than this [voxels] are removed; 0 = off |
| `despeckle_connectivity` | 1 | 1 = 6-neighbour; 2/3 = 26-neighbour (ITK has no 18-mode) |
| `despeckle_labels` | `0 3 4` | labels to treat (air, spongiosa, cortical) |

Nothing runs unless `denoise = true`. Despeckle runs **after** the median
filter, in DICOM space. The largest component of each label is always kept
(protects e.g. the exterior air).

## Python evaluation harness (parameter tuning)

```bash
python3 test_denoise_despeckle.py                       # centred 64-slice sub-volume
python3 test_denoise_despeckle.py --median-radius 1 --min-size 20 --connectivity 1
python3 test_denoise_despeckle.py --full                # whole volume (slow, RAM-heavy)
```

Prints per-label connected-component/speckle statistics for the three pipelines
(baseline / median / median+despeckle) and writes before/after comparison PNGs
into this folder. Reference numbers from the head-CT evaluation (48-slice
sub-volume): median alone removed ~98.5 % of sub-20-voxel speckle components;
median+despeckle ~99.5 %; ~3.2 % of voxels reclassified.

## Notes

- **Paths**: `output_prefix` is resolved relative to the *DICOM dir's parent*
  unless absolute (see `dicom_to_mcgpu.cpp`) — keep it absolute in your cfgs.
- **Full phantom**: set `vol_length_mm = 250.0` in the test cfgs; the .raw grows
  to ~3.8 GB.
- **RAM**: despeckle needs roughly 6–8× the DICOM volume size transiently
  (label map + per-label component map). ~12 GB peak for the 1.04-Gvoxel head CT.
- The production template `../params/dicom_to_mcgpu_template.cfg` has
  `denoise = true` with `median_radius = 1` and `despeckle_min_size = 20`;
  batch jobs generated by `../batch_dicom_to_mcgpu.py` inherit these
  automatically. Set `denoise = false` to get the old behaviour.
- Build requirements: ITK modules `ITKSmoothing` + `ITKConnectedComponents`
  (already added to `../CMakeLists.txt`). Rebuild with
  `cd build && cmake .. && cmake --build . --target dicom_to_mcgpu -j$(nproc)`.
